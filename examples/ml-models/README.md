# ML Model Examples

This directory contains examples using various ML models for audio, video, and text processing.

## Examples

- **whisper_transcription.py** - Local Whisper model for audio transcription
- **remote_whisper_transcription.py** - Remote execution of Whisper model
- **remote_ultravox.py** - Remote Ultravox model for speech-to-text
- **remote_qwen_omni_assistant.py** - Qwen2.5-Omni multimodal assistant for video analysis
- **remote_transformers_pipeline.py** - Generic Transformers pipeline for audio classification

## Key Concepts

These examples demonstrate:
- Integration with popular ML models (Whisper, Ultravox, Qwen)
- Remote offloading of ML inference
- Audio transcription and classification
- Multimodal video analysis
- Streaming ML model outputs
