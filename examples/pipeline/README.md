# Pipeline Examples

This directory contains examples demonstrating the core pipeline functionality of the RemoteMedia SDK.

## Examples

- **basic_pipeline.py** - Basic pipeline setup with audio and video processing nodes
- **test_pipeline_export.py** - Export pipeline definitions and register them with the gRPC service for JavaScript clients
- **process_media_file.py** - Process local media files through a pipeline

## Key Concepts

These examples demonstrate:
- Creating and configuring pipelines
- Adding and connecting nodes
- Exporting pipeline definitions for remote use
- Processing media streams through pipelines
- Pipeline registry integration
