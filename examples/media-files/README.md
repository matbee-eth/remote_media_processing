# Media Files

This directory contains sample media files used by the examples.

## Files

- **audio.wav** - Sample audio file for testing
- **transcribe_demo.wav** - Audio file for transcription examples
- **BigBuckBunny_320x180.mp4** - Sample video file (Big Buck Bunny)
- **draw.mp4** - Video file for multimodal analysis examples

## Usage

These files are referenced by various examples throughout the project. If an example requires a media file that's not present, you may need to:
1. Generate it using the example's built-in generation function
2. Download it from the specified source
3. Provide your own media file with the same name
