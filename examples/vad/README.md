# Voice Activity Detection (VAD) Examples

This directory contains examples demonstrating Voice Activity Detection and speech processing pipelines.

## Examples

- **test_vad_simple.py** - Basic VAD functionality test
- **test_vad_with_remote.py** - VAD with remote execution debugging
- **remote_ultravox_vad_complete.py** - Complete utterance processing with VAD and Ultravox
- **remote_ultravox_vad_triggered.py** - VAD-triggered speech processing with buffering
- **remote_ultravox_with_vad.py** - Integration of VAD with Ultravox speech-to-text

## Key Concepts

These examples demonstrate:
- Voice Activity Detection for speech/silence segmentation
- Speech buffering and utterance collection
- Pre-speech context preservation
- VAD-triggered ML model inference
- Real-time speech processing pipelines
