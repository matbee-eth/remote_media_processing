# WebRTC Examples

This directory contains examples for WebRTC integration and real-time communication.

## Examples

- **webrtc_conversation_example.py** - WebRTC server with conversation history management
- **webrtc_pipeline_registration.py** - Register WebRTC pipelines with gRPC service for JavaScript clients

## Key Concepts

These examples demonstrate:
- WebRTC server setup with aiortc
- Real-time audio/video streaming
- Conversation history and session management
- Pipeline registration for JavaScript clients
- Speech-to-speech pipelines with WebRTC
