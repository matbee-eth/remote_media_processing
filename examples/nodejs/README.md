# Node.js Client Examples

This directory contains Node.js/JavaScript client examples for integrating with the RemoteMedia SDK.

## Examples

- **nodejs-client/** - JavaScript client library and examples for connecting to gRPC services
- **nodejs-huggingface/** - Integration examples with Hugging Face models from JavaScript

## Key Concepts

These examples demonstrate:
- JavaScript/Node.js client setup
- gRPC communication from JavaScript
- Pipeline execution from JavaScript clients
- Streaming data between JavaScript and Python
- Integration with ML models from JavaScript
